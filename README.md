# Monte Carlo: Simulación – Cálculo II

Simulación web interactiva que muestra cómo se aproxima una integral definida con el método Monte Carlo (lanzando puntos aleatorios) y la compara con las sumas de Riemann.

## Integrantes

- Edgar Agudelo

## Sitio publicado

https://monte-carlo-calculo.vercel.app

Cada `git push` a `main` vuelve a desplegar el sitio automáticamente.

## Versiones

- **v2** (actual): normal truncada en el escenario de notas, intervalo de confianza del 95 %, banda de convergencia, serie de potencias para la Gaussiana, carrera con 20 corridas (RMSE) y orden observado, introducción y metodología en cada sección y fundamento matemático.
- **v1** (original): disponible en `/v1/` del sitio y en la etiqueta de Git `v1.0`.
